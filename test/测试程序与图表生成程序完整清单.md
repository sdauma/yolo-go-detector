| 2 | `cpp_arena_ablation_benchmark.cpp` | C API Arena/执行模式/线程数(inter_op×intra_op)消融 v2（定位 §4.7 C-API 延迟异常根因：原程序 `inter_op=1` 强制关闭节点间并行；决定性配置 C@intra_op=12,inter_op=默认 对比 Python@12=588.12 ms），支撑 §4.6.1 跨语言验证 | §4.6.1 / §4.7 | `cpp_arena_ablation_v2_result.json` + `cpp_arena_ablation_v2_cfg1~8.json`（原 `cpp_arena_ablation_result.json` 保留不覆盖） |

> 编译：由 `build_cpp.bat` / `build_cpp_mingw.bat` / `build_cpp_simple.bat` 生成 `cpp_baseline_benchmark.exe`；依赖 `third_party/onnxruntime-win-x64-1.23.2` SDK。Go/Python 参考基线常量（`kGoBaselineLatencyMs=738.48`、`kPythonBaselineLatencyMs=588.12`）集中定义于该文件顶部，须与论文 §4.1 同步。`cpp_arena_ablation_benchmark.cpp` 由 `build_cpp_arena.bat` 编译（硬编码 ORT SDK 绝对路径，裸 DOS 可编），输出 `cpp_arena_ablation_v2_result.json` + `cpp_arena_ablation_v2_cfg1~8.json`（原 `cpp_arena_ablation_result.json` 保留不覆盖），支撑 §4.6.1 跨语言验证与 §4.7 延迟观测。复现 §4.7：运行 `cpp_arena_ablation_benchmark.exe yolo11x yolo11x.onnx 1000`（或传 500 加速），关注 cfg4（C@intra_op=12,inter_op=默认）输出，对比 Python@12=588.12 ms，屏幕会即时打印 `[DECISIVE] CONVERGED / residual gap` 结论；一键入口：`build_all.bat` 编译全部，`RUN_ALL_STANDARD_TESTS.bat` 设 `CPP_ONLY=1` 仅跑此 C 测试。
